ZeroDesk 纯局域网床头远控 - 使用说明
============================================================

一、日常无黑框启动与开机自启（Windows 电脑端）
1. 首次运行建议右键“以管理员身份运行”【开启开机后台自启.bat】：
   - 会自动放行仅限家庭局域网 IP 段的防火墙规则，并设好开机后台无黑框自启。
2. 平时手动无黑框启动：直接双击【后台静默启动.bat】即可。
3. 查看访问网址与 6 位 PIN 码：
   - 鼠标悬停在右下角系统托盘的蓝色 Z 字图标上即可看到网址与 PIN；
   - 或右键托盘图标点击“复制访问地址与 PIN”（也可直接打开 data\config.json 查看）。
4. 防晃眼黑幕急救快捷键：在电脑键盘按 Ctrl + Alt + B 可随时强制关闭黑幕。
   若需关闭自启，运行【关闭开机自启.bat】；临时停止运行【停止被控端.bat】。

二、今晚直接用 iPhone Safari 全屏床头控制（免安装 App）
1. 确保 iPhone 与电脑连接同一个家庭 Wi-Fi。
2. 打开 iPhone 自带 Safari 浏览器，输入电脑端显示的地址（例如 http://192.168.1.7:9527）。
3. 输入 6 位 PIN 码连接一次后浏览器会自动记住。
4. 点击 Safari 底部“分享”按钮 -> “添加到主屏幕”，从桌面图标打开即可全屏无地址栏使用！
5. 触控手势：单指滑光标 / 轻点左键 / 双击按住拖拽 / 双指轻点右键 / 双指上下滑滚轮；
   点击中间“🌙 关屏黑幕”可让电脑屏幕纯黑不晃眼（手机画面照常显示）。

三、云端一键打包原生 iOS 客户端 (.ipa) 并自签安装
1. 在 GitHub 新建一个私有仓库（Repo）。
2. 在桌面 ZeroDesk 文件夹中打开终端，仅需把受 .gitignore 保护后的源码推上去：
   （已配置 .gitignore，绝不会上传本地 PIN 码、MAC、exe 或缓存，体积 < 100KB）
   git init && git add . && git commit -m "ZeroDesk" && git push ...
3. 在 GitHub 仓库网页点击顶部 Actions -> 选择“Build ZeroDesk Unsigned iOS IPA” ->
   等 2~3 分钟编译完成后，下载产物 ZeroDesk-unsigned.ipa。
4. 用 iPhone 常用自签工具（全能签 / ESign / Sideloadly / AltStore / TrollStore）
   导入 ZeroDesk-unsigned.ipa 签名安装，首次打开允许“本地网络”权限即可！

四、100% 零残留彻底卸载
以后不想用了，只需右键或直接双击【一键彻底清理.bat】（会自动请求管理员权限）：
等待提示“系统级规则已全部清除”后，直接把桌面上的 ZeroDesk 文件夹拖进回收站即可。
